# Portafolio de Desarrollo

Ingeniero Informático titulado, orientado al desarrollo de aplicaciones web, plataformas operacionales y soluciones geoespaciales.

## Perfil técnico

**JavaScript · TypeScript · React · Node.js · Fastify · PHP · Laravel · MySQL · PostgreSQL · APIs REST · Git/GitHub · Mapbox/MapLibre · GeoJSON**

## Proyectos destacados

### SIG-ONE | Plataforma GIS operacional

Plataforma web para visualización y análisis de información territorial orientada a la gestión de emergencias. Incluye capas geográficas, consulta por coordenadas, recursos operacionales, focos, quemas, fuentes de agua, torres de detección y análisis de proximidad.

**Tecnologías:** JavaScript, PHP, MySQL, Mapbox GL / MapLibre, GeoJSON y APIs REST.

### Sistema de Selección de Personal

Sistema web para administrar procesos de postulación, documentos, citaciones, entrevistas, evaluaciones, ranking y reportes de selección de personal.

**Tecnologías:** Laravel, Livewire, PHP, MySQL, Tailwind CSS, DomPDF y PhpSpreadsheet.

### Dispatch Platform

Consola web de despacho para registrar eventos mediante coordenadas, localidad o selección sobre mapa; analiza información operacional cercana y permite preparar un despacho.

**Tecnologías:** React, TypeScript, Vite, Node.js, Fastify, Zod, PostgreSQL, APIs REST y MapLibre.
